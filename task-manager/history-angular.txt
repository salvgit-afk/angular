PROGETTO
--------
- Percorso (PC lavoro): /home/salvatore/work/angular/task-manager
- Angular 22, standalone components, SSR + hydration (provideClientHydration),
  zoneless (provideZonelessChangeDetection), Tailwind, TypeScript 6.
- Test runner: VITEST (non Jasmine/Karma). angular.json usa
  "@angular/build:unit-test"; tsconfig.spec.json ha types "vitest/globals".
  Decisione presa con l'utente: restare su Vitest (default di Angular) invece
  di migrare a Karma; il corso (lezione 16) parla di Jasmine/Karma, quindi
  bisogna tradurre: spyOn -> vi.spyOn, jasmine.createSpy -> vi.fn(),
  .and.returnValue -> .mockReturnValue, fakeAsync/tick -> vi.useFakeTimers().
- Dipendenze NgRx installate: @ngrx/store, @ngrx/effects, @ngrx/store-devtools
  (v22). Attenzione: npm install va lanciato DENTRO la cartella del progetto
  (una volta l'utente l'ha lanciato in ~/work/angular e ha creato file
  spazzatura; e' stato ripulito).
- Comandi utili:
    npx ng serve
    npx ng test --watch=false
    npx ng test --watch=false --include src/app/<file>.spec.ts
  (i test sotto WSL sono lenti: da ~15s a ~5 minuti)
- Git: branch main. Ultimo commit: 0f3b160 "avanzato fino a lezione 9".
  TUTTO il lavoro delle lezioni 10-16 e' NON COMMITTATO. Consigliato
